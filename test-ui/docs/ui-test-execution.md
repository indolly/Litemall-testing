数据处理：每条测试使用独立浏览器会话。交易场景保存原购物车内容及勾选，结束后恢复。测试订单取消并逻辑删除，临时地址逻辑删除，SKU 库存恢复检查通过。

首次运行发现并修正了两个测试脚本问题：购物车金额定位器同时匹配父子元素，触发 Playwright strict mode；订单清理假设详情含数字 status 字段，而实际 API 返回 handleOption。修正为定位唯一合计元素，并根据订单允许动作决定取消、删除。首次运行遗留测试订单 79 已取消并逻辑删除，库存由 99 恢复至 100。

范围：本轮没有执行实际支付，也没有据此推断其他浏览器、真机或小程序自动化结果。
