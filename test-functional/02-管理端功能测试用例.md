# 02 管理端功能测试用例

> 早期设计底稿。正式版本及本次修订以 [Excel 用例库](Litemall功能测试用例.xlsx) 为准，结果见[评审与执行证据索引](case-review.md)。管理端同时关注业务码、数据保存、操作日志及角色权限。

## A. 登录、工作台与个人中心

| ID | P | 用例 | 前置/数据 | 操作 | 预期 |
|---|---:|---|---|---|---|
| A-AUTH-001 | P0 | 管理员正确登录 | 有效管理员和验证码 | 输入正确信息登录 | 登录成功；返回 token、角色和权限；进入工作台 |
| A-AUTH-002 | P0 | 密码错误/账号不存在 | 有效账号错误密码、随机账号 | 分别登录 | 明确失败；无 token；不泄露敏感信息 |
| A-AUTH-003 | P1 | 验证码为空/错误/过期 | 有效账号 | 分别提交 | 均被拒绝；刷新后旧验证码不可继续使用 |
| A-AUTH-004 | P1 | 连续登录失败 | 有效账号 | 多次输入错误凭据 | 按项目规则记录/限制；服务不崩溃；日志可追踪 |
| A-AUTH-005 | P0 | 未登录访问后台 API/页面 | 清除 token | 访问工作台及增删改接口 | 跳转登录或 401；不得返回后台数据 |
| A-AUTH-006 | P0 | 普通角色访问无权限功能 | 创建受限角色 | 直接点击或构造 URL/API | 菜单不可见且服务端拒绝；不能仅靠前端隐藏 |
| A-AUTH-007 | P0 | 退出登录 | 已登录 | 退出后使用旧 token | 会话失效；旧 token 不能继续访问 |
| A-AUTH-008 | P1 | 修改管理员密码 | 已登录且知道旧密码 | 输入正确旧密码和合法新密码 | 修改成功；旧密码失效；新密码登录成功 |
| A-AUTH-009 | P1 | 修改密码异常 | 错误旧密码、两次不一致、弱密码 | 提交 | 被拒绝；原密码仍有效 |
| A-DASH-001 | P1 | 工作台统计 | 已有用户/商品/订单/库存数据 | 打开工作台并查询数据库基线 | 统计值与约定口径一致；点击入口正确 |
| A-DASH-002 | P2 | 工作台空数据 | 空测试库或筛选无数据 | 打开 | 数值为 0 且无图表异常 |
| A-PROFILE-001 | P1 | 通知读取/删除 | 当前管理员有多条通知 | 查看、标记、删除和批量删除 | 未读数、列表和状态同步；不能操作他人通知 |
