## 2. “覆盖全”的边界

本轮覆盖当前代码具备的功能模块及主要业务规则，包含正常、异常、边界、状态、权限、重复操作和跨端一致性。以下专项会与功能用例关联，但后续独立执行：浏览器/设备兼容性、系统化安全测试、性能重复实验和 UI 自动化。

## 3. 用户端覆盖矩阵

| 模块 | 源码锚点 | 主要覆盖 |
|---|---|---|
| 首页与基础信息 | `WxHomeController`、`WxIndexController`、首页页面 | 首页数据、缓存、关于商城、空数据和异常降级 |
| 认证与个人信息 | `WxAuthController` | 账号/微信登录、注册、验证码、重置、绑定手机、资料、退出、鉴权 |
| 分类 | `WxCatalogController` | 一级/二级分类、当前分类、空分类、上下架联动 |
| 搜索 | `WxSearchController` | 默认词、热词、历史、联想、清空、特殊字符 |
| 商品 | `WxGoodsController` | 列表、筛选、排序、分页、详情、规格、库存、关联商品、无效 ID |
| 品牌/专题/团购 | `WxBrandController`、`WxTopicController`、`WxGrouponController` | 列表详情、关联商品、活动状态、参团限制 |
| 购物车 | `WxCartController` | 加购、快速购、修改、勾选、删除、数量、库存、结算、跨用户 |
| 优惠券 | `WxCouponController` | 领取、兑换、可用性、门槛、期限、重复领取、订单占用与释放 |
| 地址 | `WxAddressController` | 新增、修改、默认、删除、地区、字段校验、跨用户 |
| 订单 | `WxOrderController`、`WxOrderService` | 结算、提交、金额、库存、支付、取消、发货、收货、删除、评价 |
| 售后 | `WxAftersaleController` | 申请、金额、取消、后台受理/拒绝/退款、状态同步 |
| 互动与用户中心 | 收藏、足迹、评价、反馈、用户中心 Controller | 收藏切换、足迹、评价权限、反馈、计数和数据隔离 |
| 文件与客服 | `WxStorageController`、`WxMsgController` | 上传下载、非法文件、微信客服签名/消息回调 |
| 端差异 | 小程序页面与 H5 路由 | 导航、授权、返回、刷新、缓存、网络中断和登录失效 |

## 4. 管理端覆盖矩阵

| 模块 | 源码锚点 | 主要覆盖 |
|---|---|---|
| 登录与工作台 | `AdminAuthController`、`AdminDashbordController` | 验证码、登录、退出、身份信息、未授权/无权限 |
| 会员管理 | 用户、地址、收藏、足迹、历史、反馈 Controller | 查询筛选、分页、详情、状态更新和数据隔离 |
| 商城管理 | 地区、品牌、分类、订单、售后、问题、关键词 | CRUD、层级关系、状态流转和引用约束 |
| 商品管理 | `AdminGoodsController`、评论 Controller | 商品/SPU/SKU/规格/属性创建编辑删除、库存和上架状态 |
| 推广管理 | 广告、优惠券、专题、团购 Controller | CRUD、活动时间、门槛、状态、批量操作和用户端联动 |
| 系统管理 | 管理员、角色、通知、日志、对象存储 | 账号、角色权限、通知生命周期、日志查询、文件管理 |
| 配置管理 | `AdminConfigController` | 商场、运费、订单、微信配置的读取、保存、校验和生效 |
| 统计 | `AdminStatController` | 用户、订单、商品统计口径、空数据和权限 |

## 5. 测试方法

| 方法 | 在本项目中的应用 |
|---|---|
| 等价类 | 正确/错误账号，存在/不存在商品，可用/不可用优惠券 |
| 边界值 | 数量 0、1、库存 N、N+1，金额 0、门槛前后，文本最大长度 |
| 状态迁移 | 订单创建→支付→发货→收货；售后申请→受理/拒绝→退款 |
| 决策表 | 是否登录、是否有库存、是否勾选、是否满足优惠门槛组合 |
| 场景法 | 登录—搜索—加购—结算—提交—取消/支付—收货—评价/售后 |
| 错误推测 | 双击提交、刷新重试、重复取消、过期优惠券、断网恢复 |
| 权限测试 | 未登录、普通管理员无权限、用户 A 操作用户 B 的资源 |
| 数据一致性 | UI、HTTP 业务响应、MySQL 记录和服务端日志四层核对 |

## 6. 优先级规则

| 优先级 | 规则 | 示例 |
|---|---|---|
| P0 | 交易主链、金额库存、数据越权、不可逆操作 | 提交订单、扣减/恢复库存、跨用户订单访问、角色权限 |
| P1 | 重要异常、边界、管理 CRUD、内容联动 | 库存不足、地址校验、优惠券期限、商品上下架 |
| P2 | 低风险展示、易用性和非核心查询 | 空状态样式、排序展示、返回路径 |
