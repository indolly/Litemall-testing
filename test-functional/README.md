# Litemall 功能测试用例

围绕用户端、管理端和跨端业务闭环设计 249 条功能用例，覆盖正常流程、异常输入、边界值、状态迁移、权限与数据一致性。

| 工作表 | 数量 |
| --- | ---: |
| 用户端用例 | 135 |
| 管理端用例 | 89 |
| 跨端闭环 | 25 |
| 合计 | 249 |

优先级分布：P0 123 条，P1 117 条，P2 9 条。

## 文件

- `Litemall功能测试用例.xlsx`：正式功能测试用例，共 249 条，包含“用户端用例”“管理端用例”“跨端闭环”三个工作表。
- `00-测试范围与覆盖矩阵.md`：说明测试依据、范围、优先级和模块覆盖关系。
- [用例评审与结果关联](case-review.md)：本次评审修正、已有执行结果及缺陷关联。

Excel 每张工作表统一使用八个字段：用例编号、用例标题、模块、优先级、前置条件、测试步骤、测试数据、预期结果。

## 使用约定

1. 用例库按当前源码功能模块及主要业务规则组织。
2. P0 覆盖核心交易、金额、库存、权限和状态流转；P1 覆盖重要异常和边界；P2 覆盖低风险展示与易用性。
3. 用例库管理验证目标；接口、UI、安全和兼容性报告管理运行结果，通过编号、场景及缺陷记录进行关联。
4. H5 和小程序共享后端业务规则，但页面导航、授权、缓存、网络和组件差异必须分别执行。
5. 微信登录、支付、短信等场景使用对应的真实配置、沙箱或合法 Mock，并在执行记录中注明环境。

## 执行顺序

1. 先执行用户登录—搜索—商品详情—加购—结算—提交订单—取消/确认的 P0 主链路。
2. 再执行库存、金额、优惠券、重复操作、跨用户访问和售后状态等 P0/P1 风险用例。
3. 执行管理端商品、订单、售后、角色权限和配置用例。
4. 执行跨端闭环，核对页面、接口、数据库和日志证据。
